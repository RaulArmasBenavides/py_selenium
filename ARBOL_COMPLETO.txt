================================================================================
FLUJO DE UN TEST DE PRINCIPIO A FIN
================================================================================

1️⃣  Usuario ejecuta:
    $ pytest stracon/modules/asignacion_formatos/test_asignacion_formatos.py::TestAsignacionFormatos::test_asignar_formato_exitoso

2️⃣  Pytest carga:
    ✓ conftest.py (raíz) → driver global
    ✓ stracon/conftest.py → driver de STRACON
    ✓ config.py → settings desde .env

3️⃣  Test setup (@pytest.fixture):
    ✓ Crea AsignacionFormatosPage
    ✓ AsignacionFormatosPage hereda de BasePage
    ✓ Navega a módulo usando SidebarPage

4️⃣  Test ejecuta:
    ✓ self.page.asignar_formato("Formato A", "Juan")
      → pages.py llama click() y fill()
      → BasePage maneja waits automáticos
      → shared/logger.py registra acciones

5️⃣  Test verifica:
    ✓ assert self.page.verificar_asignacion()
    ✓ BasePage.is_text_present() busca texto

6️⃣  Teardown:
    ✓ Screenshot en fallo
    ✓ Limpia cookies
    ✓ Driver quit


================================================================================
ATAJOS PARA NAVEGAR
================================================================================

¿Quieres...?

✅ Ejecutar todos los tests
   $ pytest stracon/

✅ Ejecutar un módulo específico
   $ pytest stracon/modules/asignacion_formatos/ -v

✅ Ejecutar un test específico
   $ pytest stracon/modules/asignacion_formatos/test_asignacion_formatos.py::TestAsignacionFormatos::test_asignar_formato_exitoso

✅ Ejecutar con reportes HTML
   $ pytest stracon/ --html=report.html

✅ Ejecutar en paralelo (rápido)
   $ pytest stracon/ -n auto

✅ Ver logs y prints
   $ pytest stracon/ -v -s

✅ Parar en primer fallo
   $ pytest stracon/ -x

✅ Crear nuevo test
   → Lee CHECKLIST_NUEVO_TEST.md

✅ Entender estructura
   → Lee ESTRUCTURA_DEL_PROYECTO.txt

✅ Ejecutar comandos
   → Lee RUN_TESTS.md
